IT 630: Data Science and Scalable Data Systems

Fall 2026 · 4 credits · Computer Science

Required for Analytics and Data Science majors. Elective for Computer Science and Information Technology majors, and for Data Science and Analytics minors. Not writing intensive.

What
Build the data foundation that dashboards, machine learning, and AI applications actually run on.
How
Acquire, shape, query, validate, and serve data, and be able to defend the number at the end of it.
Then
Diagnose why two defensible analyses disagree: grain, missingness, leakage, denominators, and definition drift.

Learning outcomes 1-3 of 8.

Course learning outcomes
Outcome
Apply theory, techniques, and tools throughout the data science lifecycle and employ the resulting knowledge to satisfy stakeholders' needs.
Acquire data from files, APIs, and web sources.
Transform messy, nested, or incomplete data into usable analytical structures.

Learning outcomes 4-6 of 8.

Course learning outcomes
Outcome
Use SQL and modern data tools to query, validate, and explain data.
Diagnose why data analyses disagree, including grain, missingness, leakage, denominator errors, and definition drift.
Build data artifacts that are reproducible, documented, and testable.

16 topic areas structure the course.

Earlier topics

  • Course frame and the data lifecycle

  • Data modeling for analytics

  • Files, databases, warehouses, and lakehouse concepts

Later topics

  • Performance and cost basics
  • Analytics at scale
  • Data for machine learning
